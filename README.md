## 🔐 الداشبورد (لوحة التحكم)

1. افتح `dashboard.html` (من نفس رابط الموقع: `…/dashboard.html`)
2. **الباسورد الافتراضي:** `mena2026` (غيّره من تبويب Settings)
3. من الداشبورد تقدر:
   - تعدّل **كل** النصوص (الاسم، الأقسام، المشاريع، الشهادات، بيانات التواصل…)
   - تضيف / تحذف مشاريع، شهادات، مهارات، خبرات، خدمات، آراء، نقاط
   - **ترتيب العناصر** بأسهم ↑↓
   - ترفع صورة جديدة أو ترجع للصورة الافتراضية
   - **ترفع صور لمعرض أي مشروع** وتحذفها
   - تحط كود كل مشروع (Arduino/C++/Python) وروابطه
   - **إظهار / إخفاء أي قسم كامل** من تبويب Settings
   - **➕ Add Anything**: أنشئ أقسامك الخاصة بأي محتوى (نصوص، كروت، تاجز، لينكات، صور) ورتّبها وادخلها القائمة
   - **🎨 اختيار لون الموقع** من تبويب Settings (سايان/زمردي/بنفسجي/كهرماني/وردي)
   - **معاينة حية** من تبويب Preview + زرار **📱 Mobile view** لمعاينة شكل الموبايل
4. **زرار Save** يحفظ تعديلاتك → صفحة العرض بتقرأها تلقائيًا (نفس المتصفح)
5. **📦 Download updated site** ينزّل نسخة index.html مدمجة بتعديلاتك — ارفعها على أي استضافة وهتظهر للجميع
6. **⬇ Export / ⬆ Import** لحفظ واسترجاع نسخة احتياطية من البيانات

> ⚠️ الداشبورد لازم يتفتح من رابط الموقع (http/https) مش من فتح الملف مباشرة، عشان زرار "Download updated site" يشتغل.

## ✉️ تفعيل الفورم الحقيقي (Formspree)

1. اعمل حساب مجاني على [formspree.io](https://formspree.io) وأنشئ Form جديد
2. انسخ الـ Form ID (مثل `abcd1234` من الرابط `https://formspree.io/f/abcd1234`)
3. افتح الداشبورد → تبويب Contact → حط الـ ID في خانة **Formspree form ID** → 💾 Save
4. من دلوقتي أي رسالة من الزوار هتوصلك على إيميلك مباشرة (لو الخانة فاضية بيرجع للإيميل العادي mailto)

## 🖥️ مميزات صفحة العرض

- 🌐 **عربي / إنجليزي** بزرار تبديل (ع / EN) في النافبار
- 🌓 وضع ليلي / نهاري + شريط تقدم التمرير + تأثير ماوس متوهج
- 🧰 قسم **Services** (ما تقدمه) + 💬 قسم **Testimonials** (مخفي حتى تملأه)
- ➕ **أقسام مخصصة** (Add Anything) — أضف أي قسم بأي محتوى تحبه من الداشبورد
- 🖼️ معرض صور للمشاريع (تنقّل + تكبير + كيبورد ← → Esc) + رفع صور جديدة من الداشبورد
- 💻 نافذة Code لأكواد المشاريع + زرار نسخ
- 📞 اتصال مباشر + 💚 واتساب + 🔗 لينكدإن + 🐙 GitHub
- ✉️ **فورم تواصل حقيقي** (يرسل لـ Formspree) + روابط **تحقق الشهادات**
- 📤 **زراير مشاركة** في الفوتر (نسخ الرابط / واتساب / لينكدإن / فيسبوك)
- 📱 **PWA** — الموقع يشتغل أوفلاين ويتثبّت كتطبيق
- 🖨️ تنسيق طباعة نظيف (Ctrl+P)
- 🎴 كروت متحركة (3D Tilt) + جزيئات متحركة

## 🌐 النشر مجانًا

1. ارفع **index.html** (المنزّل من الداشبورد) + **dashboard.html** + ملفات الـ PDF على GitHub
2. **Settings → Pages → Deploy from branch → main → /root**
3. هتاخد لينك زي `https://username.github.io/...`

(أو اسحب الملفات على [Netlify Drop](https://app.netlify.com/drop))

## 🔧 للمطورين

عدّل ملفات `source/` ثم نفّذ:

```bash
cd source
python3 build.py
```

سيُعاد توليد `index.html` بالنسخة المجمّعة (مع علامة `window.__BAKED_CONTENT__` اللي بيستخدمها الداشبورد للدمج).
