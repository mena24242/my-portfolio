## 🔐 الداشبورد (لوحة التحكم)

1. افتح `dashboard.html`
2. **الباسورد الافتراضي:** `mena2026` (غيّره من تبويب Settings)
3. الامكانيات:
   - تعديل **كل** النصوص
   - إضافة / حذف مشاريع، شهادات، مهارات، خبرات، خدمات، آراء، نقاط
   - ترتيب العناصر ↑↓
   - رفع صورة جديدة + صور لمعارض المشاريع
   - كود كل مشروع وروابطه
   - **🔘 أزرار مخصصة للمشاريع**: أضف أي عدد أزرار بأي اسم (Datasheet، Report، Video…) كل زرار بلينك أو نص — والزرار الفاضي/غير المعمول مش بيظهر في الصفحة
   - **📎 مرفقات لأي عنصر**: ارفع ملفات (PDF/Excel/صور) أو ضيف لينكات (فيديو YouTube/Drive) على المشاريع والشهادات والخبرات والخدمات والآراء والأقسام المخصصة
   - إظهار / إخفاء أي قسم
   - ➕ **Add Anything**: أقسام مخصصة بأي محتوى
   - 🎨 اختيار لون الموقع
   - 👁️ معاينة حية + 📱 معاينة موبايل

## 🚀 التشغيل محليًا (مع حفظ دائم)

```bash
cd portfolio
python3 server.py
```

- الموقع: `http://localhost:8080/`
- الداشبورد: `http://localhost:8080/dashboard.html`

> لما تدوس Save في الداشبورد → التعديل بيتكتب في `index.html` فورًا ويثبت للجميع.

---

## 🌐 النشر مجانًا

1. ارفع محتويات المجلد على GitHub
2. **Settings → Pages → Deploy from branch → main → /root**
3. هتاخد لينك زي `https://username.github.io/...`

(أو اسحب الملفات على [Netlify Drop](https://app.netlify.com/drop))

> ⚠️ على الاستضافات الثابتة (GitHub Pages / Netlify) مفيش سيرفر يكتب في الملفات.
> بعد أي تعديل من الداشبورد دوس **📦 Download updated site** واستبدل `index.html` في GitHub.

> 💡 غيّر الرابط في `sitemap.xml` و `robots.txt` لرابطك الفعلي بعد النشر.

## ✉️ تفعيل الفورم الحقيقي (Formspree)

1. اعمل حساب مجاني على [formspree.io](https://formspree.io) وأنشئ Form جديد
2. انسخ الـ Form ID
3. الداشبورد → Contact → حط الـ ID في **Formspree form ID** → Save
4. الرسايل هتوصلك على إيميلك مباشرة (لو فاضية بيرجع للإيميل mailto)
